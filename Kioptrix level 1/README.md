# 📝 Kioptrix Level 1

**Kioptrix Level 1** is a vulnerable virtual machine from the **VulnHub** platform.

The purpose of this project is to demonstrate not only successful vulnerability exploitation, but also the ability to identify **multiple attack vectors** that lead to the same objective.

---

## 🎯 Objective

Perform a complete penetration testing workflow, including:

- 🛰️ Network Reconnaissance
    
- 🔍 Service Enumeration
    
- 🌐 Web Server Analysis
    
- 📂 SMB Enumeration
    
- 🔎 Vulnerability Assessment
    
- 🚀 Initial Access
    
- 👑 Full System Compromise
    
- 📝 Security Reporting
    

---

# 📂 Solutions

This repository contains **two independent compromise scenarios** for the same target machine.

| Solution      | Primary Attack Vector                       | Tools Used                          |
| ------------- | ------------------------------------------- | ----------------------------------- |
| 📁 Solution 1 | **Apache mod_ssl (OpenFuck)** vulnerability | Nmap, Nikto, Searchsploit, OpenFuck |
| 📁 Solution 2 | **Samba trans2open** vulnerability          | Nmap, Metasploit, Searchsploit      |

# 📌 Key Takeaway

A single system can often be compromised through **multiple attack paths**.

This project presents two independent exploitation scenarios based on different vulnerable services running on the same target.

It demonstrates an approach that goes beyond exploiting the first vulnerability found. Instead, it emphasizes analyzing the entire attack surface, evaluating multiple options, and selecting the most appropriate exploitation path based on the information gathered during reconnaissance and enumeration.
